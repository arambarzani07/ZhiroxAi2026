# Cashierynwe installed-version probe — candidate source only

Approved application identity: com.zhirox.cashierynwe.pos, electron-builder 26.0.12 UUIDv5 2a8a9551-9aff-5f3e-9f5e-71e0ff32278e. The native Windows probe uses query-only registry access to the exact uninstall key in both HKLM views and loaded user hives. No external commands, registry writes, UI, arbitrary path input, POS database access, account names or credentials. It emits a bounded version observation and timestamp. Missing or inaccessible hives do not prove absence; conflicting or malformed records refuse a version. This is registered-version evidence only, not proof the executable is running, Authenticode is valid, or the update fully completed.

The future signed Relay candidate must include both version source files and apply tools/patch_cashierynwe_version_snapshot.py to its exact reconstructed cloud source before compiling. The existing authenticated cloud snapshot publisher carries the fixed field cashierynwe_installation on its normal interval, without a new remote command or permission bypass. Existing published/candidate version artifacts are not modified. The existing signed update chain, canary, health and rollback gates are required for deployment under a new immutable version. No live deployment or installed POS version is claimed by this PR.
